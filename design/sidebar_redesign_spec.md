### 1.1 规范

| 项 | 规格 |

### 1.3 Qt 实现约束（工程师必读）

- **Qt 无法从 SVG `d` 字符串构造 `QPainterPath`**，两个可行做法，选其一：
  - **推荐 A**：`app/ui/nav_icons.py` 里每枚图标一个绘制函数，用 `QPainter` 基础图元实现
    （`drawRoundedRect` / `drawLine` / `drawEllipse` / `drawArc` / `drawPolyline`）。
    7 枚图标全部只由直线、圆角矩形、圆、圆弧构成，无需 path 解析；颜色直接由 `QPen(color)` 控制，
    **天然支持按状态换色**，且高分屏缩放清晰、无外部资源依赖。
  - 备选 B：`QSvgRenderer().load(bytes)` 渲染到 `QPixmap`；换色需把 SVG 里的 `currentColor`
    字符串替换成目标色再 load。**注意**：`QIcon` 加载后无法再改色，必须走自绘。
- `SidebarWidget._add_group` 里 `header.setIcon(_icon(...))` 改为使用新的自绘按钮；
  `_icon()` / `GROUP_ICON` / `_ICON_ONLY_QSS` 三个旧产物**全部删除**（P4/P7 一并解决）。

## 3. 动效规格

总原则：**只动 transform / opacity / 颜色**；退出动画比进入短 25%；**禁止回弹与弹性曲线**；
所有时长走统一 token，便于一键关闭。

```python
MOTION = {
    "hover":   120,   # OutCubic
    "press":    80,   # OutQuad
    "group_in": 220,  # OutQuart
    "group_out":160,  # InOutCubic
    "rail_in":  240,  # OutQuart
    "rail_out": 180,  # OutCubic
    "chevron":  180,  # OutCubic
    "stagger":   18,  # 子项错峰步进
}
```

### 3.1 鼠标移动（hover）

| 项 | 规格 |
|---|---|
| 时长/缓动 | 120ms `QEasingCurve.Type.OutCubic` |
| 变化 | 背景 transparent → `bg_hover`；图标与文字 `text_mute` → `text`；chevron `text_faint` → `text_mute` |
| 位移 | **无位移、无缩放**（Notion 的原味就是纯色变） |
| 实现 | QSS 无 transition → 需自绘按钮用 `QPropertyAnimation` 驱动 `hoverProgress: 0→1`，在 `paintEvent` 里对颜色做线性插值 |
| 简化做法 | 允许 L1 阶段直接用 QSS `:hover` 瞬变（120ms 内人眼几乎等价），L2 再上插值 |

### 3.2 鼠标点击（press）

| 项 | 规格 |
|---|---|
| 按下 | 80ms `OutQuad`：背景 → `bg_select`，图标/文字 → `text` |
| 松开 | 立即回到 hover 态，并**同步触发**该组的展开/收起动画与 chevron 旋转 |
| 位移 | 无缩放（Notion 点击反馈也是纯色）；如确需"按压感"，只允许背景加深，**不要 scale** |
| 长按/连点 | 动画未结束时再次点击：停止旧动画、从当前进度反向插值，不叠加 |

### 3.3 大类折叠 / 展开

| 项 | 规格 |
|---|---|
| 展开 | 220ms `OutQuart`：子项容器 `maximumHeight` 0 → `sizeHint().height()`，同时 opacity 0 → 1 |
| 收起 | 160ms `InOutCubic`：反向；**无错峰** |
| 子项错峰 | 仅展开时：每项延迟 `index × 18ms`，位移 4px 上移 + 淡入；**最多 6 项封顶**（总 stagger ≤ 108ms） |
| Chevron | 180ms `OutCubic`，0°（朝右）↔ 90°（朝下），与展开动画并行 |
| 标题态 | 展开后标题文字 `text` + 600；收起后回 `text_mute` + 500 |
| **坑 1** | 动画结束必须 `setMaximumHeight(QWIDGETSIZE_MAX)`，否则后续子项增删会被截断 |
| **坑 2** | `QGraphicsOpacityEffect` 与 QSS 背景同时使用时可能互相覆盖；opacity 只加在**子项容器**上，不要加在按钮上 |
| **坑 3** | 第一帧高度取 `sizeHint().height()` 前需先 `box.setVisible(True)` 并 `QApplication.processEvents()` 或 `layout()->activate()` |

### 3.4 侧栏整体展开 / 收起

| 项 | 规格 |
|---|---|
| 展开 | 240ms `OutQuart`：宽度 60 → 240 |
| 收起 | 180ms `OutCubic`：宽度 240 → 60 |
| 并行轨道 | ① 宽度 ② 大类文字 opacity（**收起时立即淡出 100ms；展开时延迟 80ms 淡入 120ms**）③ pin 按钮淡入淡出 ④ 底部挂件淡出 |
| 子项 | 收起过程中随容器整体裁切，不单独动画 |
| **坑 4** | 侧栏是 `setFixedWidth` —— 动画期间必须改为动画 `minimumWidth` 与 `maximumWidth` 两条并行，结束后再 `setFixedWidth(target)` |
| **坑 5** | 内容区 `QStackedWidget` 会随宽度重排；若掉帧，收起时先隐藏子项容器再动宽度 |
| **防抖（P9）** | `enterEvent` 延后 **80ms** 展开（鼠标掠过不触发）；`leaveEvent` 延后 **120ms** 收起；期间再次进入则取消定时器 |

### 3.5 收起态（60px 图标列）补充

- 图标水平居中（列宽 60，图标 20 → 左边距 20px）。
- **每枚图标必须 `setToolTip(大类名)`**（P6），tooltip 延迟 400ms 出现。
- 收起态 hover 表现与展开态一致（背景 `bg_hover`，图标 `text`）。
- 收起态点击 = 展开侧栏 + 展开该组（保持现有行为）。

### 3.6 减少动效（reduced motion）

- 在 `style.py` 暴露 `MOTION_ENABLED`（读 `QSettings("lawfirm","prefs")`），默认 True。
- 关闭时：所有 `duration` 设为 1ms，直接落到终值；**保留颜色变化，去掉位移与缩放**。
- 这是硬要求，不是可选项（前庭敏感人群约占 35%）。

## 7. 附：不建议做的事

- ❌ 给图标加品牌色 / 多色（破坏 Notion 单色克制感，且 60px 图标列会显脏）
- ❌ 用 emoji（渲染随系统字体变化，Win10 下大小不一致）
- ❌ 缩放 / 回弹 / 弹性曲线（2015 年审美，且会拖慢高频导航）
- ❌ 阴影、渐变、发光（与现有 palette 的无阴影基线冲突）
- ❌ 给大类行加"选中"高亮块（选中态属于子项，大类只做"已展开"的轻强调）

## 一、项目概述

**目标**：根据「销项文档 + 发票台账」得出每张发票对应经办人的开票金额与收退款情况，在桌面软件中展示 3 张收款表（支持右击查看红冲信息），并可导出 Excel。配套预收款管理、退款确认、手动补录历史数据、快照/撤销等系统能力。

**技术栈**：Python 3.13 + PySide6 + SQLite（WAL）+ openpyxl；`run_app.bat` 双击启动。
**同步**：整个 `lawfirm_app\` 目录放入 Seafile/坚果云同步文件夹；软件退出时自动 checkpoint（WAL 合并回单一 db 文件）；约定同一时间单机使用。

## 二、输入台账（真实格式已核实）

### 2.1 销项文档（每月一本）
- 命名：`销项导出2025.1.xlsx` 等（文件名含年月，格式不固定：`销项2025.01` / `销项202502` / `销项导出2025.1`）
- 结构（第 2 行表头，第 1 行标题）：序号 | 发票号码 | 发票种类 | 开票日期 | 发票状态 | 凭证号 | 货物、应税劳务及服务 | 购方名称 | 价税合计 | 不含税金额 | 税率 | 税额 | **备注**
- 发票号码唯一；发票状态列全为"正常"
- **红字发票识别 = 价税合计为负**
- **红冲关联（权威来源）**：红字发票备注 `被红冲蓝字数电票号码：24332000000398937755 红字发票信息确认单编号：3306022501100030` → 解析原正数发票号码（"被红冲蓝字数电票号码："后 20 位数字）
- 正数发票备注一般为空

### 2.2 发票台账（每月一本，4 个 sheet）
- 命名：`2025.1台账.xls` / `2025.2台账.xlsx`（`YYYY.M台账`）；sheet 名跨月不统一（`202501已开票已入账` / `202502已开票已入账` / `应收账款`），按关键词识别
- **sheet1 已开票已入账**（本月开票且已收/部分收，含红字发票）
- **sheet2 已开票未入账**（本月开票且未收/部分收）
- **sheet3 应收账款**（以前账期发票的收款信息；含期外发票：开票日期早于导入月份，需接受并入库）
- **sheet4 已入账未开票**（预收款：未开票）
- 公共列：序号 | 开票日期 | 发票号码 | 对方 | 金额（开票总额）| 经办人 | 备注 | 案号
- sheet4 特例：第一列为**收到日期**（收款日期），发票号码为空，备注为预计开票信息（如"25.2.5开"）
- **经办人列解析**：
  - 单名全额：`胡坚` → 占全额
  - 多人带金额：`徐志庆4500、柳立中4500`（顿号分隔）；`徐志庆8万、徐琦45000、傅强1万`（万单位）
  - 红字规范化：红字发票经办人金额一律存负数（台账写正数 `徐志庆4500` → 存 `徐志庆-4500`）
  - 校验：经办人开票金额合计 = 发票开票金额
  - sheet4 经办人可为空；`朱云，黄宝根`（逗号分隔无金额）= 平摊
- **备注列解析（sheet1/2/3）**：
  - 空 = 未收款
  - 纯日期（`25.1.2` / `24.12.20-21` / `25.2.11冲掉`）= 全额收款，取**最早日期**为收款日期（精确到月）
  - 收款记录列表（`25.10.24收3000,10.31收2000` / `25.8.28收到16000，25.10.31收8000，还剩2.2万未付`）= 部分/多笔收款：解析每笔（日期+金额），支持"收/收到/付"动词、万单位、省略年份（继承前笔）
  - `冲XX发票XXXX` = 红冲信息（**不作权威**，以销项备注为准）
  - **备注 = 截至该月的累计收款全史**（跨月重复出现时，以最新台账记录为准）

### 2.3 费用台账（每月一本）
- 命名：`费用台账2025.1.xlsx`
- 结构：费用名称 | 专票号码 | 经手人 | 经办人 | 费用金额 | 税额 | 不含税金额 | 费用类型 | 凭证号 | 一级科目 | 二级科目
- 不含税金额 = 费用金额 − 税额（导入校验）
- 本期仅导入落库，不参与 3 张收款表

### 2.4 职工清单（职工花名册，基础数据）
- `职工清单.xlsx`：姓名 | 类型（合伙/聘用/兼职/挂靠）| 备注
- **软件首次启动需初始化**：导入职工花名册（模板 = 职工清单.xlsx 格式，可手动逐条添加），初始化完成前不能导入台账
- 花名册可随时重新导入（覆盖式）/手动增删改；基础数据模块可扩展（后续加会计科目、费用类型等）
- **校验规则**：发票台账 + 费用台账导入时，经办人名（含 sheet4 预收款经办人）**必须出现在花名册中**；未匹配 → 阻止导入并列出名单，加入花名册后重新导入

## 三、核心业务规则（21 项确认）

### 3.1 收款认定
| 情形 | 规则 |
|---|---|
| 备注空 | 未收款，已收 = 0 |
| 备注纯日期 | 全额收款，已收 = 开票金额，收款日期 = 最早日期（精确到月） |
| 备注收款列表 | 每笔金额累加 = 已收金额；剩余应收 = 价税合计 − 已收 |
| 跨月重复出现 | 以**最新台账记录**为准（备注是累计全史） |

### 3.2 经办人收款拆分
- **全额收款**：经办人已收 = 经办人开票金额
- **部分收款**：按收款记录时间顺序逐笔处理——每笔在**未收齐**经办人间**平均分摊**；经办人累计已收达到其开票金额即收齐、退出分摊池；平均分摊超出其开票金额的部分转给其他未收齐经办人
- **结果可手动修改**（特殊情况人工调整）

### 3.3 红字发票与退款
- 红字发票正常列行（价税合计为负、经办人金额为负）
- 统一公式：**剩余应收 = 价税合计 − 已收金额**（对所有发票成立）
- 红字发票"已收金额" = −Σ已确认退款金额（未退 = 0；已退 5000 → 已收 −5000；剩余应收 = −9000 −(−5000) = −4000）
- **退款规则**（需求 2.9）：原正数发票当月开具 → 不退；以前月份开具且未收款 → 不退；以前月份开具且已收款（部分/全部）→ 需退款
- 跨年原票（未导入）→ 标记"原票未导入"，手动补录后自动判定
- 退款**手动确认**：金额 + 日期（可多次、可部分退款），独立 `refund` 表
- 结算表数据源：按 refund_date 聚合各月/各年退款额（退本年/退上年）

### 3.4 预收款（sheet4）
- sheet4 记录预收款（收到日期列 = 收款日期，备注为预计开票信息）
- 完整管理：导入存档 + 列表展示 + 导出
- **核销**：系统按**案号**（+金额校验）给出匹配建议，**用户手动确认**后核销；核销后预收款金额成为该发票"已收金额"（收款日期 = 预收收到日期）
- **部分核销**：预收款余额继续挂账，待后续开票再核销

### 3.5 历史数据（手动补录）
- 只导入 2025 年起数据（无期初文档）
- 手动补录：发票 + 经办人拆分 + 收款记录 + 退款记录，复用主表并标记 `source='manual'`
- 按 `source` 可筛选查询所有手动补录数据；手动补录的发票正常参与 3 张收款表计算
- 撤销导入不影响手动补录数据

## 四、数据模型

```sql
-- 发票主表（销项 + 台账 sheet1/2/3 + 手动补录）
CREATE TABLE invoice (
    invoice_no      TEXT PRIMARY KEY,     -- 发票号码
    invoice_date    TEXT NOT NULL,        -- 开票日期(YYYY-MM-DD)
    buyer           TEXT,                 -- 购方名称
    total_amount    REAL NOT NULL,        -- 价税合计(开票总额)
    kind            TEXT,                 -- 发票种类
    status          TEXT,                 -- 发票状态(正常)
    voucher_no      TEXT,                 -- 凭证号
    goods           TEXT,                 -- 货物/服务
    net_amount      REAL,                 -- 不含税金额
    tax_rate        TEXT,                 -- 税率
    tax             REAL,                 -- 税额
    orig_invoice_no TEXT,                 -- 原正数发票号码(红冲关联, 来自销项备注)
    remark          TEXT,                 -- 销项备注
    case_no         TEXT,                 -- 案号(来自台账)
    source          TEXT NOT NULL DEFAULT 'import',  -- import/manual
    import_batch_id INTEGER,              -- 所属导入批次(用于撤销)
    created_at      TEXT DEFAULT (datetime('now','localtime'))
);

-- 经办人拆分
CREATE TABLE charge_detail (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    invoice_no      TEXT NOT NULL REFERENCES invoice(invoice_no),
    person_name     TEXT NOT NULL,        -- 经办人
    billing_amount  REAL NOT NULL,        -- 开票金额份额(红字为负)
    source          TEXT NOT NULL DEFAULT 'import',
    import_batch_id INTEGER,
    UNIQUE(invoice_no, person_name)
);

-- 收款明细（台账备注解析 + 手动补录 + 预收款核销）
CREATE TABLE collection (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    invoice_no    TEXT NOT NULL REFERENCES invoice(invoice_no),
    amount        REAL NOT NULL,          -- 本次收款金额(正数)
    receipt_date  TEXT NOT NULL,          -- 收款日期(精确到月 YYYY-MM)
    source        TEXT NOT NULL DEFAULT 'import',  -- import/manual
    import_batch_id INTEGER,
    note          TEXT
);

-- 退款（手动确认, 可多次）
CREATE TABLE refund (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    red_invoice_no  TEXT NOT NULL REFERENCES invoice(invoice_no),
    orig_invoice_no TEXT,                 -- 原正数发票号码(冗余)
    refund_amount   REAL NOT NULL,        -- 本次退款金额(正数)
    refund_date     TEXT NOT NULL,        -- 退款日期(精确到月, 手动确认)
    note            TEXT,
    created_at      TEXT DEFAULT (datetime('now','localtime'))
);

-- 预收款（sheet4）
CREATE TABLE prepayment (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    received_date TEXT,                   -- 收到日期(收款日期)
    buyer         TEXT NOT NULL,          -- 汇款方
    amount        REAL NOT NULL,          -- 预收金额
    person_text   TEXT,                   -- 经办人原文
    case_no       TEXT,                   -- 案号
    remark        TEXT,                   -- 备注(预计开票信息)
    source        TEXT NOT NULL DEFAULT 'import',
    import_batch_id INTEGER
);

-- 预收款核销记录
CREATE TABLE prepayment_offset (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    prepayment_id INTEGER NOT NULL REFERENCES prepayment(id),
    invoice_no    TEXT NOT NULL REFERENCES invoice(invoice_no),
    offset_amount REAL NOT NULL,          -- 本次核销金额
    offset_date   TEXT NOT NULL,          -- 核销日期(手动确认)
    confirmed     INTEGER NOT NULL DEFAULT 1
);

-- 员工（职工花名册：模板导入 + 手动）
CREATE TABLE staff (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL UNIQUE,     -- 姓名(唯一, 经办人校验键)
    staff_type  TEXT NOT NULL,            -- 合伙/聘用/兼职/挂靠
    is_active   INTEGER NOT NULL DEFAULT 1,   -- 1在职/0停用
    note        TEXT,
    source      TEXT NOT NULL DEFAULT 'import',  -- import(模板导入)/manual(手动)
    created_at  TEXT DEFAULT (datetime('now','localtime'))
);

-- 导入批次（支撑撤销/重导/存档追溯）
CREATE TABLE import_batch (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    batch_type   TEXT NOT NULL,           -- invoice(销项)/ledger(发票台账)/expense(费用)/staff(职工)
    period       TEXT NOT NULL,           -- 账期 YYYY-MM
    file_name    TEXT NOT NULL,           -- 原始文件名
    archive_path TEXT,                    -- 存档路径
    file_hash    TEXT,                    -- 文件哈希
    imported_at  TEXT NOT NULL,
    status       TEXT NOT NULL DEFAULT 'active'  -- active/rolled_back
);

-- 快照
CREATE TABLE snapshot (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL,            -- 快照名(自动: 导入前自动快照/手动)
    created_at  TEXT NOT NULL,
    db_backup   TEXT NOT NULL,            -- db 备份文件路径
    note        TEXT
);
```

**关键计算口径**：
- 发票已收金额 = Σ collection.amount（该发票）
- 发票剩余应收 = total_amount − 已收金额（统一公式，含红字发票）
- 红字发票已收金额 = −Σ refund.refund_amount（未确认退款时为 0）
- 经办人已收 = 按 3.2 规则分摊（自动 + 可手动修改，存 charge_detail 冗余或独立分摊表）
- 经办人剩余应收 = 经办人开票金额 − 经办人已收
- 结算表退款数据源 = refund 按 refund_date 聚合

## 五、功能清单

### 5.0 初始化与基础数据
- 首次启动 → 初始化向导：导入职工花名册（姓名|类型|备注）或手动添加
- 初始化完成前不能导入台账
- 花名册管理：重新导入（覆盖式）/ 手动增删改 / 停用
- 基础数据模块可扩展（后续增加其他基础数据）

### 5.1 导入模块
- 逐本导入 + 按月份整组导入（A+B 结合）
- 自动识别类型（销项/发票台账/费用台账/职工清单）与账期（文件名解析年月）
- 经办人列解析、备注解析（日期/收款列表/万单位/省略年份）
- 红字识别（金额负）与红冲关联（销项备注）
- 校验：经办人合计=开票总额；红冲金额≥0；sheet1+sheet2 合计=销项合计；费用不含税=金额−税额
- 解析失败/未匹配经办人 → 报告列表，标红提示
- 导入前自动快照；原始文件存档至 `data/archive/<账期>/`

### 5.2 三张收款表
| 表 | 列 | 要点 |
|---|---|---|
| 发票收款总表 | 开具日期、发票号码、购买方名称、价税合计、经办人、已收金额、剩余应收、备注 | 备注=收款日期+经办人金额（如"张三1000王五2000"）；右击→红冲信息 |
| 经办人发票收款总表 | 开具日期、发票号码、购买方名称、开票总额、经办人、开票金额、已收金额、剩余应收、备注 | 一票多经办人拆多行；备注=收款日期；右击→红冲信息+其他经办人金额 |
| 经办人发票收款表 | 同总表 | 顶部经办人下拉，只列该经办人发票 |

- 默认全量展示，支持筛选：开票月份 / 购方搜索 / 经办人 / 来源（导入、手动补录）
- 一键导出 Excel
- 红冲信息弹窗：列出该发票（正数→其红字；红字→其原正数）及对应金额

### 5.3 预收款管理
- sheet4 导入存档 + 列表展示 + 导出
- 核销建议（按案号+金额）→ 手动确认；部分核销余额挂账

### 5.4 退款确认
- 红字发票右击 → 确认退款：填金额 + 日期（可多次、可部分）
- 退款明细可查（按发票/按月）

### 5.5 手动补录
- 添加发票（含经办人拆分）+ 添加收款 + 添加退款
- source='manual'，可按来源筛选；参与全部计算

### 5.6 系统能力
- 导入撤销（按批次，不影响手动数据）、重新导入（覆盖式）
- 快照：手动保存/恢复/删除 + 导入前自动快照（仅同类型同账期已有 active 批次、
  即真会覆盖时才自动快照；zip 压缩存储，恢复兼容旧目录格式；启动时自动清扫
  未被引用的孤儿快照；快照存本机 `%LOCALAPPDATA%\lawfirm_app\snapshots`）
- 原始导入数据存档可查看
- Seafile/坚果云同步适配：退出时 checkpoint、启动时 WAL checkpoint（崩溃/强杀
  残留的 -wal 在下次启动合入主库）、启动自检
- 可观测性：诊断埋点默认关闭（环境变量 `LAWFIRM_DIAG=1` 开启）；日志
  RotatingFileHandler（1MB×3）存本机 `%LOCALAPPDATA%\lawfirm_app\logs`
- 结算口径守护：无法解析的日期不入计算但必须警告可见（结算页警告条+日志）；
  负金额收款只冲减该经办人应收份额、不计入收款（回写弹窗直接拦截负数录入）

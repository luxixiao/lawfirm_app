## 本版范围（v1.0 基线以来新增/完成）
- 列布局系统：显示/隐藏、冻结(常驻保护列)、顺序、列宽 四态统一管理 + 严格填充算法 + 列设置弹窗
- 排序角标：改为贴角实心直角三角（自绘表头 AccentHeaderView，绕开 QSS 覆盖 setBackground 的限制）
- 费用台账页重做（与销项/发票台账同构，全字段展示）
- 发票台账工作表列加月份（如 `2025-03应收账款`）
- 导入校验放宽：经办人拆分纯人名+集合一致即视为沿用首月拆分，不再误报"经办人拆分不一致"
- 去掉导入校验页"逐行手动修正"按钮
- 导航重构为 5 大类；侧栏"个人结算总表"改名"各类报表"
- 退款模块：独立退款台账 + 结算表"退本年/退上年"按年度分桶聚合
- 发票补录方案 D：独立发票台账页 + raw_invoice 双写 + sync to invoice 工作流
- 结算表内「开票收入表」「业务收入表」Tab 实现（含模板表导出）
- 销项导出表结构调整（新增凭证号列 + 整表改名）
- 列布局事件过滤器 `_win` 防御性兜底（修复旧进程/未初始化时的 AttributeError 崩溃）

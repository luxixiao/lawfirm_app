# 交付说明：开票收款统计模块 v1.0

> 交付日期：2026-08-21｜技术栈：Python 3.13 + PySide6 6.11 + SQLite(WAL) + openpyxl

## 运行方式

双击 `lawfirm_app\run_app.bat` 启动（自动激活 venv）。

## 已实现功能（P1~P6）

### 导入
- 职工花名册（模板：职工清单.xlsx）— 首次初始化
- 销项文档（红字识别 = 金额为负；红冲关联 = 备注"被红冲蓝字数电票号码："）
- 发票台账 4 sheet（sheet 名自动识别；经办人列解析：顿号/逗号/万单位/红字负数化；备注解析：全额日期/收款列表/省略年份/剩余未收）
- 费用台账（账面费用金额校验；"徐琦合伙"类型后缀自动清洗）
- 校验规则：经办人必须在花名册（阻止导入）；sheet1+sheet2 合计 = 销项合计（需先导销项）；红冲金额 ≥ 0
- 逐本导入 + 文件夹批量导入；文件名自动识别类型与账期

### 三张收款表
- 发票收款总表（8 列 + 备注"日期 经办人金额"）
- 经办人发票收款总表（一票多经办人拆行）
- 经办人发票收款表（单经办人下拉筛选）
- 筛选：开票月份 / 购方搜索 / 来源（导入 vs 手动补录）/ 经办人
- 右击菜单：查看红冲信息 / 查看其他经办人金额
- 一键导出 Excel

### 计算引擎
- 已收金额：备注累计全史、跨月以最新记录为准
- 经办人分摊：全额 = 开票金额；部分 = 平均分摊 + 收齐退出
- 红字发票：已收 = −Σ退款，剩余应收 = 价税合计 − 已收（统一公式）
- 退款判定：当月不退 / 以前未收不退 / 以前已收需退 / 原票未导入标记

### 预收款 / 退款 / 手动补录
- 预收款列表 + 核销到发票（按案号建议、手动确认、部分核销挂账、核销金额计入发票已收）
- 退款确认：手动填金额+日期，可多次可部分
- 手动补录：发票 / 收款 / 退款（source='manual'，可按来源筛选，撤销导入不受影响）

### 系统能力
- 导入批次记录 + 撤销（不影响手动数据）
- 快照：手动保存/恢复/删除 + 导入前自动快照（自动快照保留最近 20 份）
- 原始文件存档至 `data\archive\<类型>\<账期>\`
- 同步适配：退出时自动 checkpoint（WAL 合并回单文件）；整个 `lawfirm_app\` 目录放入 Seafile/坚果云同步文件夹，约定单机使用

├── app/
